# Password Security Checker
The program’s messages are displayed in Polish
A beginner-friendly Python program that checks a password against five basic criteria:

- At least 10 characters
- At least one uppercase letter
- At least one lowercase letter
- At least one digit
- At least one special character

The program awards one point for each criterion met and displays a basic strength rating from very weak to very strong.

## Requirements

- Python 3
- Visual Studio Code with the Python extension

## How to run

1. Open `password-security-checker.py` in Visual Studio Code.
2. Click **Run Python File** (▶) in the top-right corner.
3. Enter a password in the terminal panel.

## Note

This project is for learning and provides only a basic estimate. It does not check whether a password is commonly used or has appeared in a data breach.
